# baton: credit and license

This file ships with the review room's lesson guidance (SKILL.md, diagrams.md and spec.md in this folder). It is never
sent in an agent's prompt.

The three files are adapted from baton, https://github.com/BenjaminLu/baton, commit
0ccff28a2fba09eeed5ef33b129cdb6ce402dc11: SKILL.md, references/diagrams.md and references/spec.md; the report's layout in
the review room (public/review-room.js, public/review-room.css) follows templates/packet.html. Crew Studio's changes: the
reader is the review room's captain (one register), the page is the room's lesson report built from the tutor's scenes,
Studio's board_draw items (arch, decision, item, states, sequence) take the place of hand-made SVG and the diagram-design
skill, Studio's citations take the place of GitHub links, there is no context handoff, no render or verify script, no
PDF, and a lesson's chapters are enforced by Studio.
