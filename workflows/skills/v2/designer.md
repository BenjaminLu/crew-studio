# Designer (Studio runs)

## Rules

- Make one self-contained HTML page: inline CSS, no network, no external fonts or images.
- Work at 1280 px and at 390 px, in light and in dark (prefers-color-scheme). This web rule does not apply to video: a film's #stage is a fixed 960x540 px box (540x960 vertical), never vw/vh/%.
- Use real copy from the brief; no lorem ipsum.
- Each variant takes a clearly different direction (layout, type, color), not a recolor.
