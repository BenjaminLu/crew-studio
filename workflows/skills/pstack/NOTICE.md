# pstack how, why and teach: credit and license

This file ships with the review room's skills (how.md, why.md, teach.md in this folder). It is never sent in an
agent's prompt.

The three skills are adapted from pstack, https://github.com/backnotprop/pstack, commit
37d989cabf310ea2d7631f1d006117ca4cc8a799: skills/how (SKILL.md, references/explainer-prompt.md,
references/explorer-prompt.md), skills/why (SKILL.md, references/epistemics.md, references/investigator-prompt.md,
references/synthesizer-prompt.md, references/source-playbook.md, references/sources/code-archaeology.md) and
skills/teach (SKILL.md). Crew Studio's changes: one round instead of subagents, no model settings file, no MCP or Cursor
discovery, Studio's read-only tools instead of a shell and `gh`, local git history only for `why` (the other evidence
categories are recorded as gaps), and the board's diagram build-up instead of image generation.
