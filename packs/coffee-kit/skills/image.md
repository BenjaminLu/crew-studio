# Coffee image profile — version 2

This profile adds the coffee image to the Worker contract above. The brief
supplies the approved plan and, for a revision, the pinned reference image and
its annotations; the operating manual has the image adapter's details.

- Ask for one image that serves its place on the page: subject, composition and negative space, light, style and the brand palette. Add no objects, text, logos or claims the captain did not approve.
- A revision edits the pinned reference image: change what the annotations mark, keep the rest. Without a reference image, hold; never pretend an edit.
- A new image is a proposed fix, not a verified one. Report the actual provider, model and effort.
