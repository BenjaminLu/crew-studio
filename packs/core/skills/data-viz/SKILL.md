# Data visualization

- Write the question the chart answers as its title, or the finding it shows.
- Pick the form from the question: change over time is a line, comparison is a bar, part of a whole is a stacked bar, relation is a scatter.
- Bars start at zero. Axes are labeled with units. Scales do not change between charts that are compared.
- Label lines and bars directly instead of using a far legend when you can.
- Use color to mean something, consistently; keep it readable in both themes and for color-blind viewers.
- Show the source and the date of the data.
- Never hide a gap, an outlier or a small sample; say so in a note.
- Prefer one clear chart to several busy ones.
