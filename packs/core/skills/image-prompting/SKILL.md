# Image prompting

- State the subject first, then composition (framing, angle, where the subject sits), light, palette, style and medium.
- Say what must not appear: text, logos, extra limbs, a watermark, a busy background.
- Fix the aspect ratio and size to where the image will be used, and leave room for any text laid over it.
- Keep a written style line (palette, light, lens, texture) and reuse it word for word across images and rounds, so a set looks like one set.
- Change one thing per revision and say which, so the next round is comparable.
- Never ask for a real person's likeness or a brand's mark without the captain's say.
- Check the result against the prompt and the brief before you hand it on.
