# First workflow authoring tutorial — initial core

Open Workflows → First workflow tutorial, or choose Build my first workflow in the first-use guide. Describe a goal, prepare a Firstmate chat message (review and send it yourself), preview the explicitly labeled free starter, then save it into the actual workflow editor. The browser retains the goal locally. Saving a starter creates a workflow version, not a task, and needs no staffing configuration or model job. A lost creation response holds further creation to avoid duplicates; inspect the saved workflow ID.

The starter is a captain confirmation followed by Done. It is not an AI-generated personal workflow and does not compare proposals. Actual model-generated graph persistence, inline worker/reviewer model editing, guided Run, compare/refine and personal-template publication remain follow-up work. Existing Run permission and staffing checks remain intact. The coffee example remains available separately.

Validation: offline actual-server browser fixture tests local draft persistence, chat prefill without send, labeled JSON preview and actual workflow/editor save with zero Task or model requests.
