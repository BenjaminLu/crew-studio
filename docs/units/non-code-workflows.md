# Native non-code workflows

What: install five bundled workflow templates onto Studio's existing persisted engine: web prototype, documents, video, file organization and the deterministic image-to-README lane. Artifact production and revisions use Studio's providers, immutable artifact versions and shared locators. Automated checks refine drafts before a final human acceptance card. Acceptance shows proved checks and needs-your-eye items; capability gaps remain explicit.

Why: existing domain engines are callable from Labs, but the native runtime installs only code-firstmate. Untracked deliver/templates drafts are not approved implementation: they require runtime wiring, safe artifact identity and approval, automatic check/refine, honest missing-renderer/export results, and restart/cancellation evidence. No migration from v1, no external package installation and no real remote writes.

Done (tests/non-code-workflows.ts unless named otherwise):
1. createRuntime exposes all five valid, pinned bundled definitions and their checks; production modes are installed before engine.load. Saving a new definition leaves an active task on its initial pinned version.
2. Strict fixture providers produce actual self-contained web/document artifact files; a blocking check with a shared locator triggers a new agent round and immutable artifact version before the final acceptance card. Provider transcripts and task status describe the actual rounds. Final card splits proved checks from unverified human judgment.
3. Final approval applies to the exact offered artifact/version. Stale cards, failed checks, unresolved notes and missing required outputs cannot publish a different version or fake success. Historical versions remain immutable.
4. Cancellation during a revision stops the linked work and creates no approval. Restart at a waiting final card preserves the card/version; restart during work never duplicates publication or loses the pending revision.
5. Video creates its actual HTML source and reports missing optional browser/ffmpeg honestly. No required MP4 check passes without a rendered MP4. Documents export supported local formats and report unavailable formats explicitly.
6. File organization on safe temporary fixtures plans before mutation; acceptance gates apply the exact reviewed plan, leave paths outside the authorized root unchanged, refuse symlink/stale/collision plans, and retain undo evidence.
7. Trivial lane uses an existing approved pinned image and a temporary registered local repo, validates before the single local-merge card, never calls real remotes, and refuses stale inputs.
8. The legacy tests/security.ts draft is audited but not shipped: relevant native security assertions live in the scoped new suite, exercising actual tools and domain calls without broad private-file reads. Existing focused runtime/refine/artifact/document/fileorg/lane suites pass. New native workflow assertions fail on f7a7424 without the drafts/wiring.
