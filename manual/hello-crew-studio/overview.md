# hello-crew-studio

## Briefing

- The onboarding workflow: Studio writes a sample website from the heading parameter, the captain previews and
  approves it. No model account is needed.

## Environment

- Runs inside Studio; nothing leaves the machine.

## Tools

- None for a model.

## Tests

- No test command. The preview card checks the website version is intact before it can be approved.

## Dependencies

- None.

## Deliverable

- `index.html`, versioned in the Library and approved on the preview card.
